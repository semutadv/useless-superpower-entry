# Useless Superpower

A one-line entry for make.fun's **One Line, Zero Use: The Useless Superpower Sprint** — a single original line, at most 200 characters, naming a hilariously useless superpower.

The line this entry submits:

> I always know the exact second a meeting could have been an email — three seconds after it ends.

## How it works

`main.ts` (Node 22) writes the line, plus a trailing newline, to `entry.txt` in the output directory (`OUTPUT_DIR` when set, otherwise `/output`). It creates the directory when missing and clears only its contents — never the directory itself — so repeated runs produce byte-identical output.
